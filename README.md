🛡️ Message Safety Detector

📌 نبذة عن المشروع

Message Safety Detector هو تطبيق يعتمد على تقنيات الذكاء الاصطناعي وتعلم الآلة لتحليل الرسائل النصية وتصنيفها إلى رسائل آمنة أو رسائل مزعجة (Spam).

تم تطوير المشروع باستخدام لغة Python ومكتبة Scikit-learn، ويستخدم خوارزمية Multinomial Naive Bayes لتصنيف الرسائل.

🎯 أهداف المشروع

- اكتشاف الرسائل المزعجة تلقائيًا.
- تصنيف الرسائل النصية باستخدام الذكاء الاصطناعي.
- توفير واجهة سهلة للمستخدم لإدخال الرسالة وفحصها.
- المساعدة في تقليل الرسائل غير المرغوب فيها.

🧠 تقنيات المشروع

- Python
- Streamlit
- Scikit-learn
- CountVectorizer
- Multinomial Naive Bayes

⚙️ طريقة عمل النظام

1. يقوم المستخدم بإدخال رسالة نصية.
2. يتم تحويل النص إلى أرقام باستخدام "CountVectorizer".
3. يقوم نموذج تعلم الآلة بتحليل الرسالة.
4. يتم تصنيف الرسالة إلى:
   - ✅ رسالة آمنة
   - 🚨 رسالة مزعجة (Spam)

🚀 تشغيل المشروع

قم بتثبيت المكتبات المطلوبة:

pip install -r requirements.txt

ثم شغّل التطبيق باستخدام:

streamlit run main.py

📂 ملفات المشروع

- "main.py" — الملف الرئيسي للتطبيق.
- "requirements.txt" — المكتبات المطلوبة لتشغيل المشروع.
- "README.md" — معلومات وتعريف بالمشروع.
